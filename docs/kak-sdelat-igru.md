# Как сделать игру для «K1 Игры»

Для автора игры. Игра — обычная страница HTML, CSS и JavaScript без сервера. В приложение она попадает файлом `.kibgames`: это ZIP с подписью автора. Примеры: [`games/kiberpochta/`](../games/kiberpochta/), [`app/testgames/tri-rezhima/`](../app/testgames/tri-rezhima/) (три режима).

## Что игра может и чего не может

Игра работает в песочнице. Это нельзя отключить ни настройкой, ни просьбой тьютора.

| Можно | Нельзя |
| --- | --- |
| HTML, CSS, JS, картинки, звук, видео, шрифты из своего архива | Ходить в интернет и в сеть школы: `fetch`, картинки по ссылке, CDN-шрифты не загрузятся |
| `localStorage`, `sessionStorage`, IndexedDB — пока открыто окно игры | Сохранять что-то между запусками: хранилище в памяти и пропадает при закрытии |
| WebAudio, Canvas. Окно игры и так открывается на весь экран | Камера, микрофон, буфер обмена, файлы компьютера, уведомления, любые разрешения браузера, открытие других окон и сайтов |
| Узнать режим из адреса: `new URLSearchParams(location.search).get('mode')` | Узнать, кто играет: имён и учётных записей приложение не передаёт |

Значит, всё нужное кладите внутрь папки игры, шрифты тоже. Прогресс между занятиями не сохранить, поэтому делайте игру на одно занятие, около 30 минут.

Типы файлов: `html`, `htm`, `css`, `js`, `mjs`, `json`, `txt`, `png`, `jpg`, `jpeg`, `gif`, `webp`, `svg`, `ico`, `mp3`, `ogg`, `wav`, `m4a`, `mp4`, `webm`, `woff`, `woff2`, `ttf`, `otf`. Предел: 200 МБ после распаковки и 5000 файлов. Игры больше 20 МБ ученики качают только по кнопке «Играть» или когда тьютор отметил игру «На этом занятии».

## `kibgame.json`

Лежит в корне папки игры:

```json
{
  "id": "kiberpochta",
  "version": "1.0.0",
  "title": "Киберпочта",
  "description": "Отличить настоящее сообщение от ловушки мошенников, придумать надёжный пароль.",
  "authors": ["Влад"],
  "grades": "4–5 класс",
  "minutes": 30,
  "topic": "Кибербезопасность",
  "entry": "index.html",
  "cover": "cover.png",
  "minAppVersion": "1.1.0"
}
```

- `id` — латиница, цифры и дефис. Не меняйте его между версиями: по нему тьютор обновляет игру, а оценки детей остаются.
- `version` — `1.0.0`, `1.0.1` и так далее. Новую версию поднимайте при каждой правке.
- `minutes` — от 1 до 180, `grades` до 40 знаков, `topic` до 80, `authors` от 1 до 10 имён.

### Обложка

`"cover": "cover.png"` — PNG или WebP до 512 КБ, лучше 1280 × 800. Окно игры показывает её полосой 3 : 1 по центру, поэтому главное держите в полосе от 200 до 600 px по высоте. JPEG не принимается: в фотографиях часто остаются координаты GPS. Без обложки на карточке будут инициалы на штриховке.

### Режимы

Режимы необязательны. Если игра одна, без выбора, поле не нужно. Если вариантов несколько (тренировка и экзамен, разная сложность), объявите их, и на витрине появятся вкладки. Каждый режим дети оценивают отдельно.

```json
"modes": [
  { "id": "training", "title": "Тренировка", "about": "С подсказками", "cover": "cover-training.png" },
  { "id": "exam", "title": "Экзамен", "entry": "exam.html" }
]
```

От 1 до 12 режимов. `id` латиницей, цифрами и дефисом. Режим получает свой `id` в адресе страницы: `?mode=training`. `entry` у режима — своя стартовая страница, без него открывается общий `entry`. Если есть `cover` или `modes`, `kibpack` сам поднимет `minAppVersion` до 1.1.0.

## Ключ автора и упаковка

Нужен Node 22 и папка `app` репозитория (`npm ci` один раз).

```bash
cd app
npm run kibpack -- keygen vlad
npm run kibpack -- pack ../games/kiberpochta --key ~/.config/kibgames/keys/vlad.key.pem
npm run kibpack -- verify kiberpochta-1.0.0.kibgames
```

`verify` проверяет файл по тем же правилам, что приложение, и показывает **отпечаток ключа**. Его тьютор видит при публикации и вносит вас в список доверия школы.

Закрытый ключ (`*.key.pem`) нельзя передавать и класть в репозиторий. Сделайте резервную копию: если ключ потерян, новую версию игры тьютор сможет опубликовать только как замену игры другого автора, с отдельным подтверждением.

## Перед тем как отдать игру тьютору

1. Откройте игру в приложении без метки школы: `npx electron . игра.kibgames` из папки `app`, или двойным щелчком по файлу на ноутбуке, где стоит «Игры KIBERone» без метки. Пройдите её целиком.
2. Отключите интернет и проверьте ещё раз: шрифты и картинки на месте, в консоли нет ошибок загрузки.
3. Проверьте на 1366 × 768: так видят дети на школьных ноутбуках.
4. Отдайте тьютору только файл `.kibgames`. Тьютор публикует его в «KIBERone Сервер» ([`ustanovka.md`](ustanovka.md), раздел 2, шаг 7).
