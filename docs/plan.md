# План и статус

Этапы маркетплейса из [ADR-0002, раздел 7](adr/0002-marketplace.md) и [ADR-0003, раздел 8](adr/0003-vitrina.md). Каждый этап закрывается отчётом и проверкой на Windows. Постановки, отчёты и журналы проверок ведутся у авторов локально и в репозиторий не входят.

| Этап | Что | Статус |
| --- | --- | --- |
| В0 | Витрина K1 без сети: обложки, режимы, оценки | готово |
| М1 | Ключ школы, публикация, подписанный каталог, программа тьютора | готово |
| М2 | Раздача по сети, витрина по каталогу школы | готово |
| М3 | Нагрузка на Wi-Fi: слоты, предел скорости, докачка | готово |
| М4 | Оценки по сети | готово |
| М5 | Установщики, документация, установка Кириллом, пилот | установщики 1.2.0 проверены на Windows; ждут установка Кириллом, пилот, проверка на двух компьютерах и школьном ноутбуке |

## Дальше

После пилота — разбор итогов и решения по [ADR-0002, раздел 9](adr/0002-marketplace.md):

- несколько школ на одном ноутбуке тьютора или одна школа на нескольких тьюторах;
- мультиплеер: только задел, что нужно от платформы;
- идеи Кирилла: конструктор игр и что для него нужно от формата `.kibgames`.

Уже в исходниках, войдёт в 1.2.1: снятие ассоциации `.kibgames` при удалении, вопрос перед установкой более старой версии.

Не планируются: автообновление, подпись кода Windows, рейтинг учеников с никами.
