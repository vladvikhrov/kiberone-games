## Что уже есть

- Electron-приложение запускает один файл `.kibgames` в песочнице: без сети, файлов компьютера и устройств, без следов на диске. Библиотеки игр нет.
- `.kibgames` — ZIP с манифестом, хешами файлов и подписью Ed25519. Автором может быть кто угодно, ключ создаёт `kibpack`. Школа ведёт список доверенных ключей в `trusted-keys.json`.
- Тест-«взломщик» проходит на Linux. На Windows приложение ещё не запускалось, первая проверка сегодня вечером по `docs/tasks/windows-test-prompt.md`. Сейчас там проверяется нынешняя версия, а не маркетплейс.
- Установщик на GitHub Actions настроен, но ещё не запускался. `pult.py` раздаёт игры по сети без пароля.

## Цель

Полноценное приложение KIBERone для Windows: дети открывают каталог, выбирают игру, она скачивается по локальной сети и запускается. Игры доступны только внутри сети школы. Самые интересные режимы видны по оценкам детей.

## Требования

1. **Каталог.** Все игры, загруженные в локальной сети школы. Из него можно запустить любую.
2. **Роли.** Предложи, куда загружаются игры и кто это делает. Моя гипотеза, проверь её: сервер работает на ноутбуке тьютора, загружает игры только тьютор в режиме администратора, детям доступны только каталог, запуск и оценки. Определи вход администратора, что будет при утере пароля, и как сделать, чтобы ребёнок не получил эти права на общем ноутбуке.
3. **Оценки режимов.** Дети оценивают режимы, приложение показывает самые популярные. Без имён и других личных данных. Предусмотри защиту от накруток на уровне школьного класса и не обещай большего, чем реально обеспечит анонимность. Определи, что считать режимом, ведь сейчас в манифесте такого понятия нет.
4. **Защита и отсутствие утечек.** Построй модель угроз для новых частей: поддельный сервер в школьном Wi-Fi, подмена каталога и файлов, отсутствие TLS в локальной сети, ученик, изучающий трафик, накрутка оценок, загрузка вредной игры. Сеть доступна только основному процессу и только адресам локальной сети, окна игр остаются без сети. Опиши, какие данные хранятся, где и сколько, и что не покидает школьную сеть никогда.
5. **Малая нагрузка на сеть.** При входе приложение загружает каталог и в фоне скачивает файлы игр, затем игра запускается локально, без обращений к серверу. Посчитай нагрузку для 15 ноутбуков на одном Wi-Fi и игры размером от 30 КБ до 200 МБ. Предложи ограничение одновременных скачиваний, докачку, кеш по хешу и поведение при пропаже сервера.
6. **Обнаружение сервера.** Как ноутбук ученика находит сервер без ручного ввода, если это возможно, и что делать, если сеть блокирует такой способ.

## Только как задел, не проектируй полностью и не реализуй

- **Мультиплеер для будущих режимов.** Режимы пока неизвестны. Определи минимальное решение, которое принимаем сейчас, чтобы не закрыть эту возможность. Игры без сети остаются правилом по умолчанию, поэтому опиши, как мог бы выглядеть контролируемый канал и как его проверял бы тест-«взломщик».
- **Идея Кирилла: конструктор.** Ученик собирает схему из выключателей, динамика и лампочки, изучает И, ИЛИ, НЕ, может строить сеть. Другой вариант: как в Minecraft, персонаж плывёт по реке, и ученик командами строит ему путь. Это идеи, а не задача. Отметь только, какие возможности платформы им понадобятся, например сохранение работ, большие игры, совместная работа.

## Ограничения

- Ноутбуки с Windows 11, 15 учеников, один тьютор. Интернет в школе не обязателен, школ может стать больше.
- Разрабатывают два тьютора. Никакой внешней инфраструктуры и платных сервисов без явной причины.
- Текущую песочницу и формат `.kibgames` не ослабляй. Всё, что меняет формат или защиту, обоснуй отдельно.
- Коммиты и пуш не делай, давай мне команды. Репозиторий на GitHub веду я сам.
