# Проверка этапа М1 на Windows (критерий Т18)

Делает Влад на своём ПК, около 50 минут. Нужны Node 22.12 или новее и git. Проверяются Т1–Т15 и Т17 автоматически и программа тьютора руками.

Программа тьютора в этой проверке пишет данные во временные папки `k1-tutor-a` и `k1-tutor-b` в `%TEMP%`, а не в настоящую `%LOCALAPPDATA%\KIBERone Server`. Настоящих данных школы проверка не трогает. Пароль и код восстановления здесь тестовые: не используйте их потом для настоящей школы.

## Команды

Все команды в PowerShell из папки `kiberone-games\app`.

```powershell
# 1. Свежий код и зависимости
git pull
npm ci

# 2. Модульные тесты (Т1–Т11, Т15) и тест-«взломщик» без захвата трафика (Т12, Т13 = К24, Т17)
npm test
node redteam/run.js --portable

# 3. Две сборки папкой и проверка состава app.asar (Т14). Займёт несколько минут
npm run check:builds

# 4. Игры для публикации: Киберпочта, Сейф, «Три режима» в %APPDATA%\Игры KIBERone\games
npm run dev-catalog

# 5. Программа тьютора с тестовой папкой данных
npx electron desktop/tutor/main.js --data="$env:TEMP\k1-tutor-a"
```

Если `run.js --portable` спросит про брандмауэр, разрешите только частные сети: тест слушает порты 18080–18082 на вашем адресе, чтобы ловить утечки.

Команды к таблице:

```powershell
# «второй ноутбук» (шаг 19): другая пустая папка данных
npx electron desktop/tutor/main.js --data="$env:TEMP\k1-tutor-b"

# «плохие файлы» (шаг 20): программа ученика открывает битый и подделанный файл
'это не игра' | Set-Content "$env:TEMP\bitaya.kibgames"
$b = [IO.File]::ReadAllBytes("$env:APPDATA\Игры KIBERone\games\kiberpochta.kibgames"); $b[[int]($b.Length/2)] = $b[[int]($b.Length/2)] -bxor 0xFF
[IO.File]::WriteAllBytes("$env:TEMP\poddelka.kibgames", $b)
npx electron . "$env:TEMP\bitaya.kibgames"
npx electron . "$env:TEMP\poddelka.kibgames"

# «соединения» (шаг 21): сетевые соединения Electron, должно быть пусто
Get-NetTCPConnection | Where-Object { $_.OwningProcess -in (Get-Process electron -ErrorAction SilentlyContinue).Id }
Get-NetUDPEndpoint  | Where-Object { $_.OwningProcess -in (Get-Process electron -ErrorAction SilentlyContinue).Id }

# После проверки: удалить тестовые папки
Remove-Item "$env:TEMP\k1-tutor-a", "$env:TEMP\k1-tutor-b" -Recurse -Force
```
