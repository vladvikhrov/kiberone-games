# Аудит кода приложения, 01.11.2026

Проверены `app/shared`, `app/kibpack`, `app/desktop`, а также `pult.py` и вывод данных в играх. Аудит сделан чтением кода и тестами, сторонней экспертизы не было. Windows не проверялась.

## Найдено и исправлено

| Серьёзность | Проблема | Как проверено | Исправление |
| --- | --- | --- | --- |
| Высокая | Игра могла стать незакрываемой через `beforeunload`, а окно на весь экран блокировало бы ноутбук ученика | Тест К12 упал до исправления | `will-prevent-unload`, выход через `destroy` |
| Высокая | Файл с тем же `id` подменял файлы уже запущенной игры и получал её хранилище | Тест К13 упал до исправления, отдавался `IMPOSTOR` | Одна копия на `id`, автор входит в имя сессии |
| Высокая | Подписанная кем угодно игра запускалась без предупреждения, хотя ADR его обещает. Список доверия не подключён | Чтение кода, тест К14 | Предупреждение и `trusted-keys.json` |
| Высокая | Установленное приложение принимало `--no-sandbox`, `--remote-debugging-port` и запускалось как Node. Для этого нужен доступ к компьютеру или ярлыку | Проверено на Linux-сборке | Ключи запуска отклоняются, включены Electron Fuses |
| Средняя | Управляющие символы и смена направления текста позволяли подделать имя автора на экране | Модульный тест | Запрет таких символов в манифесте |
| Средняя | Упавшая игра оставляла пустое окно на весь экран | Чтение кода, тестом не покрыто | Окно закрывается с сообщением |
| Низкая | `minAppVersion` не проверялся | Модульный тест на сравнение версий | Проверка при запуске |
| Низкая | Обработчики сессии накапливались при повторном запуске игры | Чтение кода | Ставятся один раз |
| Низкая | Ключ, оканчивающийся на `.kibgames`, принимался за файл игры | Чтение кода | Аргументы с `-` пропускаются |

## Ошибки в тестах и сборке, найденные по ходу

- Проверка запуска оболочки могла пройти, пока приложение просто ждало подтверждения. Теперь автор добавляется в список доверия.
- Сборка NSIS на Linux оставила файл на 181 КБ, хотя установщик весит около 100 МБ. Причина: нужен Wine. Файл удалён, для установщика добавлена сборка на Windows.

## Критических удалённых уязвимостей не найдено

В коде не нашлось способа, которым файл `.kibgames` вышел бы из песочницы, отправил данные наружу или прочитал файлы компьютера. Это результат проверки на Linux, а не доказательство отсутствия таких способов.
