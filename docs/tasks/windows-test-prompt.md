# Проверка приложения «Игры KIBERone» на Windows

Это задание для Claude Code на компьютере с Windows. Вставь этот файл в чат целиком или попроси Claude его прочитать, находясь в этой папке.

## Контекст

Влад, тьютор кибершколы KIBERone, делает приложение для коллег и других школ. Оно запускает учебные игры для детей 4–5 класса из файлов `.kibgames`. Файл `.kibgames` — это ZIP с манифестом, подписью Ed25519 и HTML/JS-игрой. Игры может выпускать кто угодно, поэтому каждая считается недоверенной и работает в песочнице: без сети, без файлов компьютера, без устройств, без следов на диске. Стек: Electron 45, Node.

На Linux всё проверено автотестом. **На Windows приложение ещё ни разу не запускалось. Твоя задача — выяснить, работает ли оно и держит ли защиту именно здесь.** Там другая системная песочница и другая реализация WebRTC, поэтому результаты Linux не переносятся.

## Правила

- Код не меняй и не «чини». Нашёл проблему: опиши её и приложи вывод. Решения принимает Влад.
- Не выдавай предположение за результат. Что не удалось проверить, отмечай как «НЕ ПРОВЕРЕНО» с причиной.
- Не подгоняй критерии. Провал теста по неясной причине — это находка, а не помеха.
- Не отключай Защитник Windows, брандмауэр и SmartScreen глобально. Если что-то мешает, сообщи об этом как о находке.
- Отвечай по-русски. Шаги, где нужен человек, проси выполнить Влада и задавай вопрос по одному.

## Шаг 1. Подготовка

1. Сверь `SHA256SUMS.txt` через `Get-FileHash`.
2. Запиши версию Windows, тип учётной записи (администратор или нет), установленный антивирус.
3. Распакуй ZIP приложения в папку без кириллицы, например `C:\kibtest\app`. Запиши, что сказали SmartScreen и антивирус. Файл не подписан, предупреждение SmartScreen ожидаемо. Сообщи, блокирует ли что-то запуск полностью.

## Шаг 2. Автотест-«взломщик»

Нужен Node 22.12 или новее. Если его нет, спроси Влада, можно ли поставить.

```powershell
cd source\app
npm ci
npm test
node redteam/run.js --portable
```

При первом запуске брандмауэр может спросить про доступ для Node и Electron: тест поднимает локальный приёмник атак. Разрешения для Electron тоже нужны контрольному прогону. Запиши, что он спросил.

Что значат критерии:

| № | Критерий | Важно |
| --- | --- | --- |
| К1 | Настоящие игры работают в песочнице | |
| К2 | Сетевые атаки не дошли до приёмника | **Критично**, особенно `webrtc-ip` и обращения по UDP |
| К3 | Те же атаки без защиты сработали | Если каналы молчат, тест пустой и К2 ничего не доказывает. Перечисли их |
| К5–К8 | Файлы, соседняя игра, устройства, навигация | **Критично** |
| К9 | Метки нет на диске, F5 сохраняет прогресс | |
| К10 | Песочница: `sandboxed: true`, уровень `untrusted` или `low` | **Критично** |
| К11–К14 | Плохие файлы, закрытие, подмена, неизвестный автор | |

Строка «НЕ ПРОВЕРЕНО К4» в этом режиме нормальна, её закрывает шаг 3. Приведи полный вывод теста в отчёте. Если тест падает из-за особенностей Windows, разберись в причине без правки кода и опиши её.

## Шаг 3. К4: приложение не выходит в сеть

Запусти `kiberone-games.exe`, открой Киберпочту и подтверди запуск. Пока игра открыта, минуту выполняй:

```powershell
$end = (Get-Date).AddSeconds(60)
while ((Get-Date) -lt $end) {
  $ids = (Get-Process kiberone-games -ErrorAction SilentlyContinue).Id
  Get-NetTCPConnection -ErrorAction SilentlyContinue | Where-Object { $ids -contains $_.OwningProcess -and $_.State -ne 'Listen' } |
    Select-Object RemoteAddress, RemotePort, State, OwningProcess | Format-Table -AutoSize
  Get-NetUDPEndpoint -ErrorAction SilentlyContinue | Where-Object { $ids -contains $_.OwningProcess } |
    Select-Object LocalAddress, LocalPort, OwningProcess | Format-Table -AutoSize
  Start-Sleep -Milliseconds 500
}
```

Ожидается: ни одного TCP-соединения и UDP-точки. Это слабее настоящего захвата пакетов, поэтому так и укажи в отчёте. Если есть права администратора и сеть тихая, дополнительно сними `pktmon` и посмотри, есть ли DNS-запросы во время запуска приложения. На фоне работы других программ чужие пакеты приложению не приписывай.

## Шаг 4. Защита установленного приложения

Запускай `kiberone-games.exe` с этими аргументами. Каждый запуск должен завершиться сразу с кодом 2, окно не появляется:

```powershell
$exe = 'C:\kibtest\app\kiberone-games.exe'
foreach ($a in '--no-sandbox', '--remote-debugging-port=9333', '--inspect', '--disable-web-security') {
  $p = Start-Process $exe -ArgumentList $a -PassThru -Wait; "$a -> код $($p.ExitCode)"
}
$env:ELECTRON_RUN_AS_NODE = '1'
& $exe -e "console.log('NODE_RAN')"; "RUN_AS_NODE -> код $LASTEXITCODE"
Remove-Item Env:ELECTRON_RUN_AS_NODE
```

Строки `NODE_RAN` быть не должно. Проверь и целостность: сделай копию папки приложения, поменяй один байт в копии `resources\app.asar`, запусти копию. Приложение не должно запустить изменённый код. На этот счёт на Linux проверки не было, так что результат особенно ценен.

## Шаг 5. Что должен проверить человек

Попроси Влада пройти это руками и опиши каждый результат:

1. **Выбор файла.** Запуск `kiberone-games.exe` без аргументов открывает выбор файла. Выбрать Киберпочту.
2. **Неизвестный автор.** Появляется предупреждение с отпечатком `{{KEY_ID}}`, по умолчанию выбрано «Не запускать». Оба варианта работают.
3. **Список доверия.** Закрой приложение, создай `%APPDATA%\Игры KIBERone\trusted-keys.json` с содержимым `{ "{{KEY_ID}}": "Тест" }`. Теперь игра запускается без предупреждения. Убедись, что папка называется именно так и кириллица в пути ничего не ломает.
4. **Плохие файлы.** `poddelka.kibgames` и `bitaya.kibgames` показывают понятную ошибку на русском и не открывают игру.
5. **Киберпочта целиком.** Весь экран, все пять смен до удостоверения. Слышен ли звук? Нет ли обрезанного текста на экране ноутбука? Работает ли перетаскивание карточек в смене 4?
6. **Взломай сейф целиком.** Лампочки, звук, все сейфы. Посмотри на шрифты: они не загружаются из интернета, поэтому могут отличаться от задуманных.
7. **F5** сохраняет прогресс, **закрытие и новый запуск** начинают игру заново.
8. **Esc** спрашивает о выходе, по умолчанию выбрано «Продолжить». **Alt+F4** закрывает игру.
9. **Зависшая игра.** Открой `test-zavisanie`, нажми кнопку, затем Esc и «Выйти». Окно должно закрыться. Если не закрывается, это серьёзная находка: ребёнок окажется заперт в окне на весь экран. Закрывать тогда через диспетчер задач.
10. **Запуск из папки с кириллицей и пробелами**, например `C:\Игры школы\`, и файл игры с кириллицей в имени.
11. **Ноутбук без интернета.** Отключи сеть и запусти игру: всё должно работать как раньше.

## Шаг 6. Отчёт

Создай `ОТЧЁТ-WINDOWS.md` рядом с этим файлом и покажи его содержимое Владу:

1. **Вердикт одной фразой:** можно ли давать приложение детям на этой конфигурации.
2. **Система:** версия Windows, антивирус, что сказал SmartScreen.
3. **Таблица:** каждый критерий и шаг, результат (OK, ПРОВАЛ или НЕ ПРОВЕРЕНО), короткое доказательство.
4. **Находки по убыванию серьёзности:** что случилось, как повторить, вывод. Особо выдели всё, где данные могли уйти наружу или ребёнок мог застрять в окне.
5. **Полный вывод** `node redteam/run.js --portable`.

Известные ограничения, о них сообщать не нужно: нет установщика и привязки расширения, нет своего значка, стандартные свойства файла `.exe`, нет библиотеки игр (это следующий этап), есть предупреждение SmartScreen о неизвестном издателе, шрифты Сейфа пока не лежат в игре.
