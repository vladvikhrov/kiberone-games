# Показ витрины детям (критерий В13)

Цель: понять, могут ли дети без объяснений запустить игру и поставить оценку. Проверяем программу, а не детей.

**Данные о детях не собираем.** Не записываем имена, не снимаем лица и экран с ребёнком, не сохраняем, кто что поставил. В записях только «ученик 1», «ученик 2» и примерный возраст группы. После показа удалите `ratings.json` и `state.json` из `%APPDATA%\Игры KIBERone\`, чтобы тестовые оценки не смешались с настоящими.

## Подготовка (5 минут)

- Ноутбук с витриной, папка игр собрана командой `npm run dev-catalog`, интернет выключен.
- Витрина открыта, мышь подключена. Звук игр по желанию.
- 3–4 ученика по одному, на перемене или в конце занятия, по 3–5 минут на каждого.

## Что сказать

Только это, дословно: «Это новая программа с играми. Выбери любую игру и поиграй минутку. Потом закрой её». Дальше молчите и не показывайте пальцем. Если ребёнок застрял дольше 30 секунд, скажите: «Как бы ты попробовал?» Если и это не помогло, помогите и отметьте в таблице, где.

## Что наблюдать

| Шаг | Что смотрим | Ученик 1 | Ученик 2 | Ученик 3 | Ученик 4 |
| --- | --- | --- | --- | --- | --- |
| 1 | Нажал на карточку сам | | | | |
| 2 | Понял, что вкладки — разные режимы («Три режима») | | | | |
| 3 | Нашёл «Играть» сам | | | | |
| 4 | Закрыл игру сам (Esc → «Выйти» или иначе) | | | | |
| 5 | Понял окно «Как тебе?», поставил звёзды сам | | | | |
| 6 | Заметил полосу 5 секунд и «Отменить» | | | | |
| 7 | Закрыл окно оценки сам (крестик, Esc, щелчок мимо) | | | | |
| 8 | Где застрял и что сказал (своими словами, без имени) | | | | |

Отметки: «сам», «с подсказкой», «не смог».

## После показа

- Попросите одного ученика нарочно нажать не ту звезду. Успел ли нажать «Отменить» за 5 секунд?
- Спросите: «Что значат звёзды на карточке?» Ответ запишите без имени.
- Итог одной строкой для отчёта: сколько из 3–4 учеников запустили игру и оценили её сами.
