# Кирилл ставит систему по инструкции (П1)

Цель: проверить, что тьютор ставит «K1 Игры» без разработчика. Кирилл работает только по [`docs/ustanovka.md`](../ustanovka.md), Влад сидит рядом, молчит и записывает. Помогать можно, только если Кирилл застрял больше чем на 5 минут или вот-вот сделает что-то необратимое (например, выключит Smart App Control). Каждая подсказка — отдельная строка в таблице.

Нужно: ноутбук тьютора (на нём ещё нет «KIBERone Сервер»), два ноутбука учеников под записью администратора, флешка с `KIBERone-Server-Setup-1.2.0.exe`, `KIBERone-Games-Setup-1.2.0.exe` и `SHA256SUMS.txt`, распечатка или второй экран с `ustanovka.md`, файл любой нашей игры `.kibgames`, секундомер.

Что Кириллу сказать перед началом, и больше ничего: «Поставь систему по этой инструкции на эти три ноутбука и проведи пробную раздачу одной игры. Я молчу и смотрю, где инструкция плохая, а не где ошибаешься ты».
