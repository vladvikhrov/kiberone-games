## Отступления от постановки и почему

1. **4 колонки на 1366 px**, а не 3 (ADR-0003 2.1): так в макете, макет главнее.
2. **Окно оценки отдельное** (экран 3 макета), а не строка «Как тебе?» внутри окна игры (ADR-0003 2.3). Окно игры строки оценки не содержит, как в макете (экран 2).
3. **Фильтр по группам** «Все / Младшая / Средняя / Старшая», как в макете. Фильтра по теме из ADR-0003 2.1 нет. Группа вычисляется из `grades` (см. «Уточнения» в постановке) — это допущение, его надо подтвердить.
4. **Текст в окне игры 16 px**, а не 18 (ADR-0003 4.3): так в `stil-k1.md` и макете.
5. **Нет метки «✓ готово» на карточке**: в макете её нет. Для игр, которые нельзя запустить, есть метки «автор не проверен» и «обнови приложение». Состояний «качается» и «нужна связь» нет: на этапе В0 нет сети.
6. **Нет «НОВОЕ», сортировки «на этом занятии» и заставки**: для них нужны поля каталога `publishedAt` и `lesson`, их нет до М1. Порядок карточек — по названию.
7. **Шапка справа: «игры на этом ноутбуке · вход не нужен»** вместо «на связи с тьютором»: без сети это было бы неправдой.
8. **Канал `iframe` убран из К23.** Без защиты Chromium не загрузил http-фрейм в странице схемы `kibapp:` (вероятно, блокировка смешанного содержимого), поэтому канал ничего не доказывал, а правило теста такие каналы запрещает. Фреймы в окне закрыты `frame-src 'none'` и фильтром сессии. Остальные 7 каналов (скрипт из названия, `fetch`, картинка, WebSocket, `sendBeacon`, шрифт, CSS) без защиты дошли.
9. **Игры неизвестных авторов с витрины не запускаются** (предупреждения «Запустить всё равно», как при открытии файла, на витрине нет). Ребёнок не должен решать, доверять ли автору.
10. **`state.json` лежит в `%APPDATA%`**, а не в `%LOCALAPPDATA%`, как в ADR-0003. Перенос путей профиля оставил на М2.
11. **В12 проверен автоматически, а не в DevTools**: DevTools в окне витрины выключены намеренно. Эмуляция `prefers-reduced-motion` сделана через отладочный протокол в тесте.

## Найденные риски

| Риск | Что предлагаю |
| --- | --- |
| Игры с полями `cover` или `modes` не откроются в приложении 1.0.0, которое уже у Влада на Windows: ошибка «Неизвестное поле манифеста: cover» вместо «обновите приложение». Версия приложения осталась 1.0.0 | Перед раздачей поднять версию приложения до 1.1.0 и ставить таким играм `minAppVersion: "1.1.0"`. Не сделал сам: это меняет имена сборок и комплекта для Windows, решение за Владом |
| Обложка в окне игры показывается полосой 3 : 1, на карточке 1,9 : 1. Рисунок у края 1280 × 800 обрежется | Правило «главное в полосе 200–600 px» записано в `app/README.md`. На М1 можно показывать тьютору превью обрезки при публикации |
| Группы по тексту `grades` угадываются. «4–5 класс» и «дошкольники и 1 класс» распознаются, произвольный текст — нет | Решить с Кириллом: оставить так или добавить в формат поле `groups` |
| Голос, который ждёт 5 с, теряется, если закрыть приложение в эти секунды | Принято в ADR для «нет связи», здесь так же. Можно отправлять сразу при закрытии окна приложения |
| `ratings.json` на этапе В0 у каждого ноутбука свой. Это проверка подсчёта и показа, общий рейтинг класса появится с сервером (М4) | — |
| День считается по часам ноутбука ученика. Ребёнок, переведший часы, оценит ещё раз | По ADR дату даст сервер в ответе каталога (М2) |
| При запуске витрина целиком читает каждый `.kibgames` в память ради проверки. 100 игр по 200 МБ — долгий старт | На М2 проверка уходит в загрузку по каталогу, витрина будет читать только обложки из кеша |
| Сбой игры и выход по Esc всё ещё показывают системные окна (`dialog`), а ADR-0003 раздел 6 их в сборке ученика запрещает | Перевести на окна витрины на М2, вместе с экраном «Попроси тьютора» |
| Шрифты Сейфа по-прежнему с Google и в песочнице блокируются (известный долг этапа 0) | Перенести шрифты внутрь игры при следующем выпуске Сейфа |
| Тесты гонялись на Node 18.19, а README требует 22.12 | На Windows Влад прогонит на своём Node |
| Собранное приложение (`app.asar`) проверено только запуском на 8 с без ошибок в журнале. Глазами витрину в сборке не видел: на этой машине нет невидимого экрана | Шаги `windows-v0.md` из исходников; сборку проверить на М5 |
| Обложки Киберпочты и Сейфа нарисованы мной по стилю макета, авторы игр их не видели | Показать Владу и Кириллу, при желании заменить: формат примет любую PNG или WebP до 512 КБ |
