# Проверка витрины В0 на Windows (критерий В14)

Делает Влад на своём ПК. Займёт около 40 минут. Нужны Node 22.12 или новее и git. Проверяются В3–В6, В10, В11 из `etap-v0-vitrina.md`.

Ваши настоящие файлы в `%APPDATA%\Игры KIBERone\` (список доверия, игры, оценки) шаг 3 дополнит. Если там уже что-то есть, сначала сделайте копию:

```powershell
Copy-Item "$env:APPDATA\Игры KIBERone" "$env:USERPROFILE\Desktop\k1-backup" -Recurse -ErrorAction SilentlyContinue
```

## Команды

Все команды в PowerShell из папки `kiberone-games\app`.

```powershell
# 1. Свежий код и зависимости
git pull
npm ci

# 2. Модульные тесты и тест-«взломщик» без захвата трафика (В10, К23, В3–В5, В9, В11, В12)
npm test
node redteam/run.js --portable

# 3. Папка игр витрины: Киберпочта, Сейф, «Три режима», ключ разработки в списке доверия
npm run dev-catalog

# 4. Витрина
npx electron .
```

Если `run.js --portable` спросит про брандмауэр, разрешите только частные сети: тест слушает порты 18080–18082 на вашем адресе, чтобы ловить утечки.

## Что проверить руками

| № | Что сделать | Что должно быть |
| --- | --- | --- |
| 1 (В3) | Нажать «Киберпочта» → «Играть» | Игра на весь экран |
| 2 (В3) | В игре Esc → «Выйти» | Витрина, поверх окно «Как тебе?», над ним «Киберпочта» |
| 3 (В3) | То же с «Взломай сейф» | То же, подпись «Взломай сейф» |
| 4 (В3) | «Три режима» → вкладка «Свой путь» → «Играть» | Розовая страница `custom.html`, крупно «режим: custom» |
| 5 (В4) | Закрыть игру, нажать 4-ю звезду, за 5 с нажать «Отменить» | Полоса и «Записали: 4 из 5», после отмены снова «Нажми на звезду» |
| 6 (В4) | Нажать 5-ю звезду и подождать | Через 5 с «Спасибо! Оценка сохранена без имени». На карточке «Три режима» стало на одну оценку больше |
| 7 (В5) | Снова сыграть в «Свой путь» и закрыть | «Ты уже оценил этот режим сегодня. Завтра можно снова», звёзды неактивны |
| 8 (В5) | Сыграть в «Тренировку» и закрыть | Звёзды активны: другой режим можно |
| 9 (В5) | Закрыть приложение. Выполнить команду «вчера» ниже. Открыть витрину, сыграть в «Свой путь» | Звёзды снова активны |
| 10 (В6) | Закрыть приложение, выполнить команду «оценки» ниже, открыть витрину | Киберпочта: 4.3 и 37 оценок в окне игры. «Три режима» → «На время»: «мало оценок · 3 оценки» |
| 11 (В11) | Выключить Wi-Fi и кабель, открыть витрину | Всё работает, шрифты как на снимке `docs/img/v0-vitrina-1366.png` |
| 12 (В11) | При открытой витрине выполнить команду «соединения» ниже | Пусто |
| 13 | Клавиатура: Tab до карточки, Enter, Tab по окну, Esc | Окно открывается, фокус не уходит из окна, после Esc фокус на той же карточке |

Команды к таблице:

```powershell
# «вчера» (шаг 9): отметка об оценке становится вчерашней
$d = (Get-Date).AddDays(-1).ToString('yyyy-MM-dd')
'{"votedOn":"' + $d + '","voted":["tri-rezhima/custom"]}' | Set-Content "$env:APPDATA\Игры KIBERone\state.json" -Encoding utf8

# «оценки» (шаг 10): известные числа, среднее Киберпочты (1+2+12+48+95)/37 = 4.3
'{"format":1,"games":{"kiberpochta":{"default":{"1":1,"2":1,"3":4,"4":12,"5":19}},"tri-rezhima":{"timed":{"1":0,"2":0,"3":1,"4":1,"5":1}}}}' |
  Set-Content "$env:APPDATA\Игры KIBERone\ratings.json" -Encoding utf8

# «соединения» (шаг 12): сетевые соединения приложения, должно быть пусто
Get-NetTCPConnection | Where-Object { $_.OwningProcess -in (Get-Process electron, kiberone-games -ErrorAction SilentlyContinue).Id }
Get-NetUDPEndpoint  | Where-Object { $_.OwningProcess -in (Get-Process electron, kiberone-games -ErrorAction SilentlyContinue).Id }
```
