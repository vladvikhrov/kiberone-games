# Проверка этапа М2 на двух ноутбуках с Windows (критерий С12)

Делает Влад, около часа. Нужны два ноутбука с Windows в одной сети, Wi-Fi или кабель: **ноутбук тьютора** и **ноутбук ученика**. Node не нужен, всё идёт на готовых exe, как в `windows-exe.md`. На ноутбуке ученика нужна запись администратора, чтобы положить метку школы.

Программа тьютора пишет данные во временную папку `k1-tutor-m2`, настоящих данных школы проверка не трогает. Пароль тестовый.

## Что взять

Из `kiberone-games/app/dist/windows-exe/` (пересобрать: `npm run build:win-dir`, `npm run build:tutor-win-dir`, `node scripts/make-win-zips.js`):

| Архив | На какой ноутбук |
| --- | --- |
| `KIBERone-Server-1.1.0-win-x64.zip`, `K1-test-games.zip` | Тьютора |
| `KIBERone-Games-1.1.0-win-x64.zip` | Ученика |

Хеши — в `SHA256SUMS.txt` рядом с архивами. Проверка: `Get-FileHash *.zip`.

## 1. Ноутбук тьютора

PowerShell, из папки с архивами:

```powershell
Expand-Archive KIBERone-Server-1.1.0-win-x64.zip C:\K1 -Force
Expand-Archive K1-test-games.zip                 C:\K1 -Force
ipconfig    # запишите адрес IPv4 Wi-Fi или Ethernet: это адрес тьютора

# Программа тьютора с тестовой папкой данных (переменная действует только в этом окне)
$env:LOCALAPPDATA = "$env:TEMP\k1-tutor-m2"
& C:\K1\KIBERone-Server\kiberone-server.exe
```

В программе:

1. Создайте школу: название «Тест М2», пароль `тест-пароль-м2` дважды, галочка про код, «Готово».
2. «Опубликовать .kibgames» → `C:\K1\K1-test-games\games\kiberpochta.kibgames`. Автор неизвестен школе: поставьте галочку «Публикую игру неизвестного автора», «Опубликовать». Так же `tri-rezhima.kibgames` и `vzlomai-seif.kibgames`.
3. «Школа» → «Сохранить school.kibschool» на флешку.
4. Плашка «РАЗДАЧА УЧЕНИКАМ»: выберите сеть, у которой адрес совпадает с `ipconfig`, «Включить раздачу». Если Windows спросит про доступ к сети, отметьте сеть, к которой подключены (школьный Wi-Fi часто «Общественная»), и нажмите «Разрешить». Нужны права администратора.
5. На плашке появится «включена», название сети и крупно адрес: это адрес для учеников, запишите его.

## 2. Ноутбук ученика: метка школы

PowerShell **от имени администратора**, флешка с `school.kibschool` — диск `E:` (если буква другая, поправьте):

```powershell
Expand-Archive KIBERone-Games-1.1.0-win-x64.zip C:\K1 -Force

# Метка школы: только администратор может её менять, остальные только читают
New-Item -ItemType Directory 'C:\ProgramData\KIBERone Games' -Force | Out-Null
Copy-Item E:\school.kibschool 'C:\ProgramData\KIBERone Games\school.json' -Force
icacls 'C:\ProgramData\KIBERone Games' /inheritance:r /grant:r '*S-1-5-32-544:(OI)(CI)F' '*S-1-5-18:(OI)(CI)F' '*S-1-5-32-545:(OI)(CI)RX'

# Чистый кеш ученика
Remove-Item "$env:LOCALAPPDATA\KIBERone Games" -Recurse -Force -ErrorAction SilentlyContinue
```

Дальше всё под **обычной записью ученика**, не от администратора. Запуск программы: `& C:\K1\KIBERone-Games\kiberone-games.exe`. Если запись ученика другая, путь `%LOCALAPPDATA%` у неё свой, кеш там пустой.

## 3. Что проверить

| № | Где | Что сделать | Что должно быть |
| --- | --- | --- | --- |
| 1 | Ученик | Под записью ученика: `Add-Content 'C:\ProgramData\KIBERone Games\school.json' 'x'` | Отказ в доступе |
| 2 | Ученик | Запустить программу | За несколько секунд в шапке «есть связь», три игры, у Киберпочты и «Трёх режимов» обложки. Полоса «скачивается» исчезает |
| 2а | Ученик | Если при запуске Windows показала окно брандмауэра «Разрешить доступ»: снимок экрана, затем **«Отмена»** (ребёнок не сможет нажать «Разрешить» без пароля администратора) | Записать, нашёлся ли сервер после «Отмена». Это важно: входящих правил на ноутбуках учеников быть не должно |
| 3 | Ученик | Нажать «есть связь» | Окно «Связь с тьютором»: сервер — адрес тьютора, школа «Тест М2», отпечаток как в окне «Школа» у тьютора |
| 4 | Ученик | Команда «соединения» ниже, пока витрина открыта | Только адрес тьютора и порт 47800 (или пусто между опросами) |
| 5 | Ученик | Команда «захват во время игры», сразу после неё запустить «Взломай сейф» и играть до сообщения «готово» (около 90 с), затем выйти | В выводе `пакетов на порт 47800 во время игры: 0` |
| 6 | Ученик | Закрыть игру | Снова окно игры с «Как тебе?», через несколько секунд витрина опрашивает сервер дальше |
| 7 | Тьютор | «На этом занятии» у «Трёх режимов» | У ученика в течение 75 с «Три режима» встали первыми |
| 8 | Тьютор | «Выключить раздачу» | У ученика в течение 75 с «нет связи». Скачанные игры запускаются |
| 9 | Тьютор | Включить раздачу, выбрать «Взломай сейф», «Снять» | У ученика в течение 75 с «Взломай сейф» пропал с витрины |
| 10 | Ученик | Закрыть программу. `Remove-Item "$env:LOCALAPPDATA\KIBERone Games" -Recurse -Force`. Тьютор выключает раздачу. Запустить программу | Через 15 с экран «Попроси тьютора» с полем адреса |
| 11 | Ученик | Тьютор включает раздачу. Ввести адрес тьютора, «Подключиться» | «Подключились», появляются игры. После перезапуска программы адрес вводить не нужно |
| 12 | Ученик | В поле ввести `8.8.8.8` | «Этот адрес не из сети, к которой подключён ноутбук» |
| 13 | Ученик | Двойной щелчок или `& C:\K1\KIBERone-Games\kiberone-games.exe C:\K1\K1-test-games\games\kiberpochta.kibgames` (скопируйте файл на этот ноутбук) | Окно «На этом ноутбуке игры запускаются только из каталога школы» |
| 14 | Тьютор | Если на ноутбуке тьютора есть VPN: включить его и открыть список сетей в плашке раздачи | Адаптера VPN в списке нет |
| 15 | Ученик | Если на ноутбуке ученика есть VPN: включить, повторить шаг 4 | Соединения только с адресом тьютора |

Команды к таблице (PowerShell ученика, обычная запись):

```powershell
# «соединения» (шаг 4): все TCP-соединения программы за 60 секунд, без повторов
$seen = @{}
1..60 | ForEach-Object {
  $ids = (Get-Process kiberone-games -ErrorAction SilentlyContinue).Id
  Get-NetTCPConnection -ErrorAction SilentlyContinue | Where-Object { $_.OwningProcess -in $ids -and $_.RemoteAddress -notin '0.0.0.0', '::' } |
    ForEach-Object { $seen["$($_.RemoteAddress):$($_.RemotePort)"] = 1 }
  Start-Sleep 1
}
$seen.Keys
Get-NetUDPEndpoint | Where-Object { $_.OwningProcess -in (Get-Process kiberone-games -ErrorAction SilentlyContinue).Id }

# «захват во время игры» (шаг 5): нужен PowerShell от администратора (pktmon). Через 20 с после запуска команды
# начинается захват на 60 с по порту 47800. За эти 20 с запустите игру
pktmon filter remove
pktmon filter add K1 -p 47800
Start-Sleep 20; pktmon start --capture --pkt-size 0 -f "$env:TEMP\k1-m2.etl"; Start-Sleep 60; pktmon stop
pktmon etl2txt "$env:TEMP\k1-m2.etl" -o "$env:TEMP\k1-m2.txt"
"пакетов на порт 47800 во время игры: " + (Select-String -Path "$env:TEMP\k1-m2.txt" -Pattern '47800' | Measure-Object).Count
pktmon filter remove
```

После проверки:

```powershell
# Тьютор
Remove-Item "$env:TEMP\k1-tutor-m2" -Recurse -Force
# Ученик, от администратора: убрать метку школы, иначе программа останется в режиме настроенного ноутбука
Remove-Item 'C:\ProgramData\KIBERone Games' -Recurse -Force
Remove-Item "$env:LOCALAPPDATA\KIBERone Games" -Recurse -Force
```

По таблице ADR-0002, раздел 3.5: нет ping — изоляция клиентов в Wi-Fi, ping есть, а порт закрыт — брандмауэр тьютора.
