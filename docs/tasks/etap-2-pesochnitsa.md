# Этап 2: оболочка Electron, песочница и тест-«взломщик»

Постановка задачи к ADR-0001. Этап закрыт, только когда каждый критерий подтверждён запуском.

## Цель

Доказать проверкой, а не обещанием: игра из `.kibgames` работает как обычно, но не может отправить данные наружу, прочитать компьютер или другую игру и не оставляет следов на диске.

## Что входит

- Запуск файла: `electron . игра.kibgames` проверяет файл и открывает игру в песочнице.
- Модуль песочницы: протокол `kibgame://`, сетевой фильтр, запреты, отдельная сессия.
- Игра-«взломщик» и автоматический тест.

## Что не входит

Библиотека и интерфейс (этап 3), установщик `.exe`, Electron Fuses и проверка на Windows (этап 4), раздача по сети (этап 5), шрифты Сейфа (этап 0).

## Критерии приёмки

| № | Критерий | Как проверяется |
| --- | --- | --- |
| К1 | Настоящие игры работают в песочнице: Киберпочта и Сейф открываются без ошибок JavaScript | Тест и снимок экрана, который смотрю глазами |
| К2 | Ни одна сетевая атака не дошла до приёмника | Отдельный процесс-приёмник (HTTP, WebSocket, UDP) насчитал 0 обращений |
| К3 | Каждая атака действительно рабочая, тест не пустой | Те же атаки без защиты: приёмник обязан увидеть **каждый** канал. Иначе тест считается проваленным |
| К4 | Наружу не ушло ни одного пакета, включая DNS и пакеты самого Electron | Захват трафика вне приложения за весь запуск: 0 пакетов с защитой и больше 0 без неё |
| К5 | Нет доступа к файлам и Node: `file://`, `process`, `require`, выход из папки через `..` и `%2e%2e` | Атаки в игре |
| К6 | Нет доступа к другой игре, запущенной рядом | Чтение её файлов и хранилища по адресу `kibgame://<другая>/` |
| К7 | Камера, микрофон, геолокация, буфер, USB и другие устройства недоступны | Атаки в игре |
| К8 | Игра не уводит окно, не открывает новые и не запускает внешние программы (`mailto:` и другие протоколы), скачивание отменяется | Адрес окна и число окон не меняются, журнал отказов |
| К9 | На диске нет следов, а F5 сохраняет прогресс | Метка из хранилищ не находится в папке профиля и не появляется при втором запуске. `sessionStorage` переживает перезагрузку |
| К10 | Системная песочница Chromium включена, запуска с `--no-sandbox` нет | Проверка процесса и кода |
| К11 | Сломанный или поддельный файл не запускается | Приложение завершается с понятной ошибкой, окно игры не появляется |

## Границы проверки

Прогон идёт на Linux. На Windows проверку нужно повторить на этапе 4: там другая системная песочница и другая реализация WebRTC. Стенд использует сетевые пространства Linux и `/proc`, поэтому для Windows его придётся доработать: К4 и К10 там проверяются иначе.

## Результат (01.11.2026, Electron 45.2.1, Linux)

Все 11 критериев выполнены, команда `npm run test:redteam`.

- К1: автотест проверяет запуск без ошибок JavaScript и наличие текста, снимки посмотрены. Прохождение игр до конца внутри песочницы не проверялось.
- К3: `preconnect` и `dns-prefetch` исключены из обязательных каналов, потому что в Electron они не открывают соединений и без защиты. Атаки оставлены в тесте.
- К7: USB, HID и Serial проверены только отказом при запросе устройства: настоящих или виртуальных устройств этих типов на стенде нет.
- К8: переходы на `file:` Chromium отклоняет раньше наших обработчиков, поэтому они проверяются по адресу окна и числу окон, а не по журналу.
- DNS: отсутствие запросов подтверждается захватом всех пакетов, включая loopback.
