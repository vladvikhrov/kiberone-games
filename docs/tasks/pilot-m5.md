# Пилот на одной группе (П3)

Одно занятие с группой до 15 учеников. Игра — часть урока, не весь урок. Главное правило: **сбой не должен мешать уроку**. Если за 5 минут игры не дошли до ноутбуков, тьютор спокойно переходит на план Б, а «K1 Игры» разбираем после занятия.

Данные о детях не собираем: ни имён, ни фотографий и снимков экрана с детьми, ни записи голоса. В таблицах только числа и наблюдения вроде «трое не нашли кнопку».

## Накануне (30 минут, в классе)

| Что | Готово? |
| --- | --- |
| Программа тьютора стоит, школа создана, код восстановления на бумаге дома, резервная копия есть | |
| Опубликована игра урока и отмечена «На этом занятии», пробно запущена тьютором | |
| На всех ноутбуках учеников стоит «Игры KIBERone» с меткой, под записью ребёнка открывается витрина | |
| Раздача включена хотя бы на 10 минут: все ноутбуки скачали игру урока («готово» на карточке) | |
| Записан адрес ноутбука тьютора на плашке — на случай ручного ввода | |
| Зарядка для ноутбука тьютора | |
| План Б: урок по модулю без игры готов, его можно начать за минуту | |
| Знаю, что делать при сбоях: таблица «Если что-то не так» в [`ustanovka.md`](../ustanovka.md) | |

## На занятии

1. Включите раздачу в начале урока, до того как дети откроют ноутбуки.
2. Объясните задачу урока как обычно. Про звёзды отдельно не рассказывайте: проверяем, поймут ли дети сами.
3. Дети открывают «Игры KIBERone», выбирают игру урока, играют.
4. После игры — оценка. Тьютор смотрит панель «Оценки», но вслух цифры не обсуждает.
5. В конце — «Сохранить срез» в программе тьютора.
