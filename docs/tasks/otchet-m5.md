# Отчёт по этапу М5: установщики и пилот

Постановка: [`etap-m5.md`](etap-m5.md), решения Влада и уточнения — в её конце. Дата: 06.11.2026. Часть на Linux сделана и проверена (Node 18.19, Electron 45.2.1). Установщики NSIS здесь не собирались: на этой машине нет Wine, а значок и свойства exe встраивает только сборка на Windows. Их собирает и проверяет отдельный чат Claude Code на Windows по [`windows-m5.md`](windows-m5.md), промпт — [`prompt-windows-m5.md`](prompt-windows-m5.md). Установку Кириллом и пилот проводит Влад.

## Итог

Без файла программа ставится без метки, с сообщением; работает тихая установка `/S`. Удаление снимает метку, обновление не трогает.

## Отступления от постановки

Подробно — в «Уточнениях при выполнении» постановки. Коротко:

- установщики собирает чат на Windows, а не только Actions;
- заставка внутри той же страницы, не отдельное окно; стенды её убирают сразу, снимки делает отдельный скрипт;
- установщик снимает папку-ссылку на месте папки метки и ссылку на месте `school.json` — этого не было в постановке;
- снимков окон установщика в документации нет (на Linux их не снять).

## Риски

1. **Ни один установщик ещё не собирался и не запускался.** NSIS-скрипты проверены только разбором текста. Ошибки синтаксиса LogicLib, кириллица в `$INSTDIR` для `netsh`, поведение `icacls /setowner` — всё выяснится на Windows. Для этого чат на Windows может править `installer.nsh` (промпт это разрешает).
2. **Smart App Control.** На Windows 11, где он включён (бывает на свежеустановленных), неподписанный установщик не запустить вообще, кнопки «Выполнить в любом случае» нет. Подпись кода не входит в этап. В `ustanovka.md` сказано не выключать его самостоятельно, а позвать Влада.
3. **Окно брандмауэра у ученика.** Программа ученика слушает UDP для ответа на поиск сервера. Если Windows спросит про доступ и ребёнок нажмёт «Отмена», не ясно, найдёт ли ноутбук сервер без ручного адреса. Проверка — `windows-m5.md`, раздел 8.
4. **Учётные записи детей** до сих пор не проверены (ADR-0002, 12). Если ребёнок в группе «Администраторы», метку он изменить может (У8). Проверка — раздел 9.
5. **Заставка 3 с при каждом запуске.** Для детей это подсказка, но если надоест — убирается любой клавишей; при жалобах можно показывать её раз в день.
6. **Workflow не запускался.** Задание `linux` может упереться в ограничения раннера (`unshare`, песочница Chromium). Если так, это не мешает установщикам: задания независимы.
7. **Node 18 у меня.** На Node 22 тесты М5 гоняются только в Actions и на Windows у Влада (Node 26).
8. **Две копии репозитория.** Папка уходит на флешке в чат на Windows вместе с `.git`. Правки оттуда надо вернуть сюда (или пушить с Windows), иначе история разойдётся.
