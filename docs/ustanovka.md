# Установка «K1 Игры» в классе

Инструкция для тьютора. Разработчик и Node не нужны. Понадобятся ноутбук тьютора с Windows 10 или 11, ноутбуки учеников с Windows, флешка и пароль администратора от каждого ноутбука.

Займёт около 20 минут на ноутбук тьютора и по 3 минуты на ноутбук ученика.

| Программа | Файл | Куда ставить |
| --- | --- | --- |
| «KIBERone Сервер» (знак K1 на чёрном, оранжевая полоса) | `KIBERone-Server-Setup-1.2.0.exe` | Только на ноутбук тьютора |
| «Игры KIBERone» (оранжевый знак K1) | `KIBERone-Games-Setup-1.2.0.exe` | На ноутбуки учеников |

Оба файла лежат в одной папке на флешке Влада или в GitHub: Actions → «Windows build» → последний зелёный запуск → архив `kiberone-installers`. Рядом лежит `SHA256SUMS.txt`: если файл пришёл не из рук Влада, сверьте хеш (PowerShell в папке с файлом: `Get-FileHash *.exe`).

## 1. Окно «Система Windows защитила ваш компьютер»

Программы не подписаны сертификатом Microsoft, поэтому при первом запуске установщика Windows может показать синее окно SmartScreen. Нажмите «Подробнее», проверьте, что имя файла правильное, и нажмите «Выполнить в любом случае».

Если кнопки «Выполнить в любом случае» нет, а Windows пишет, что приложение заблокировано «Интеллектуальным управлением приложениями», напишите Владу. Сами эту защиту не выключайте: обратно её не включить без переустановки Windows.

## 2. Ноутбук тьютора

1. Запустите `KIBERone-Server-Setup-1.2.0.exe`. Windows спросит разрешение на изменения: «Да». Папку оставьте как есть, «Установить».
2. Установщик сам открывает порт 47800 в брандмауэре Windows, только для этой программы и только для своей сети. В конце он напомнит про код восстановления.
3. Откройте «KIBERone Сервер» с рабочего стола. На 3 секунды появится заставка с тремя шагами, её можно убрать любой клавишей.
4. **Новая школа.** Название (например, «KIBERone Приморский»), пароль тьютора не короче 10 знаков дважды.
5. Программа покажет **код восстановления** из 26 знаков. Перепишите его на бумагу и храните не в классе. Больше программа его не покажет. Поставьте галочку «Я записал код на бумагу», «Готово».
6. **Резервная копия.** «Школа» → «Резервная копия» → выберите папку на флешке, которую вы не носите в класс. В копии ключ школы зашифрован паролем.
7. **Игры.** «Опубликовать .kibgames» → выберите файл игры. Если автор не знаком школе, программа предупредит. Внесите автора в список доверия под его именем или поставьте галочку «Публикую игру неизвестного автора». Публикуйте только игры, которые вы сами запускали.
8. **Метка школы для учеников.** «Школа» → «Сохранить school.kibschool» → сохраните **в ту же папку на флешке, где лежит `KIBERone-Games-Setup-1.2.0.exe`**. Секрета в этом файле нет.

Пароль вводится только в программе тьютора. На ноутбуках учеников пароль тьютора не вводите никогда. Через 10 минут без действий программа сама закрывает ключ, раздача при этом продолжает работать.

## 3. Ноутбуки учеников

На каждом ноутбуке:

1. Войдите под записью **администратора** (не под записью ребёнка).
2. Вставьте флешку и запустите `KIBERone-Games-Setup-1.2.0.exe` прямо с неё. Файл `school.kibschool` должен лежать рядом.
3. «Да» на вопрос Windows, «Установить».
4. В конце должно появиться сообщение **«Метка школы поставлена»**. Если вместо него «Рядом с установщиком нет файла school.kibschool», программа встала без школы: положите файл рядом и запустите установщик ещё раз.
5. Выйдите из записи администратора и войдите под записью ребёнка. Откройте «Игры KIBERone»: заставка, потом витрина.

Ребёнок не может изменить метку школы: её папка `C:\ProgramData\KIBERone Games` открыта ученикам только на чтение.

Чтобы поставить быстрее, не нажимая кнопок: откройте командную строку от имени администратора, перейдите на флешку и выполните `KIBERone-Games-Setup-1.2.0.exe /S`. Через минуту программа и метка стоят, окон не будет.

## 4. Первое занятие

1. Подключите ноутбук тьютора к той же сети Wi-Fi, что и ноутбуки учеников. Включите зарядку: пока идёт раздача, ноутбук не засыпает.
2. Откройте «KIBERone Сервер», войдите паролем.
3. Плашка «РАЗДАЧА УЧЕНИКАМ»: выберите сеть класса (VPN в списке не показывается) → «Включить раздачу». Крупно появится адрес, например `192.168.1.23`: это адрес для учеников.
4. У игры урока нажмите «На этом занятии»: она встанет первой и скачается заранее на все ноутбуки.
5. Дети открывают «Игры KIBERone». Через 5–15 секунд в шапке витрины «есть связь», карточки заполняются.
6. Ребёнок выбирает игру, режим, «Играть». После игры ставит от 1 до 5 звёзд. Оценки без имён, вы видите их в панели «Оценки».
7. Если ноутбук не нашёл программу тьютора за 15 секунд, на экране «Попроси тьютора»: продиктуйте адрес с плашки, ребёнок вводит его и нажимает «Подключиться». Адрес запоминается.

**Проверка, что ноутбук настроен на вашу школу:** щёлкните по надписи о связи в шапке витрины. В окне «Связь с тьютором» есть название школы и отпечаток, они должны совпасть с «Школа» → «ОТПЕЧАТОК КЛЮЧА ШКОЛЫ» в программе тьютора.

## 5. Если что-то не так

| Что видно | Что делать |
| --- | --- |
| Ни один ноутбук не находит тьютора, а адрес вручную помогает | Точка доступа не пропускает широковещание. Ничего страшного: адрес вводится один раз. Лучше попросить администратора закрепить адрес ноутбука тьютора |
| Адрес вручную тоже не помогает | Точка доступа изолирует устройства друг от друга. Включите на ноутбуке тьютора мобильный хот-спот («Параметры» → «Сеть и Интернет» → «Мобильный хот-спот») и подключите ноутбуки учеников к нему, либо принесите свою точку доступа |
| При включении раздачи Windows спрашивает про доступ к сети | Правило установщика не сработало. Отметьте сеть и нажмите «Разрешить». Если раньше нажимали «Отмена», зайдите в «Брандмауэр Защитника Windows» → «Разрешение взаимодействия с приложением» и включите «KIBERone Сервер» для частной и общественной сетей |
| На витрине «Скажи тьютору: игры на этом ноутбуке не открываются» или «Ноутбук настроен с ошибкой» | Метка школы испорчена или от другой школы. Сохраните `school.kibschool` заново и поставьте программу поверх (шаг 3) |
| Игра «скачивается» очень долго | Нажмите на плашке «Скачать быстрее»: предел скорости снимается до выключения раздачи. Сайты у остальных станут медленнее |
| Игры совсем не доходят за 5 минут | Переходите к уроку по модулю без игр. Игры, которые уже скачались, работают и без связи |
| Забыли пароль | На экране входа «Забыли пароль?» → код восстановления с бумаги → новый пароль |
| Потеряны и пароль, и код | Создайте школу заново и поставьте программу учеников поверх с новым `school.kibschool` на каждый ноутбук |
| Ноутбук тьютора сломался или заменён | Поставьте программу тьютора на новый ноутбук, на первом экране «Восстановить из копии», выберите папку резервной копии, войдите прежним паролем. Ноутбуки учеников перенастраивать не нужно |

## 6. Обновление и удаление

**Обновление.** Запустите новый установщик поверх старого, удалять старую версию не нужно. Метка школы, скачанные игры, ключ школы, каталог и оценки остаются.

**Удаление программы учеников** («Параметры» → «Приложения»): снимаются программа, ярлыки и метка школы. Скачанные игры остаются в папке `%LOCALAPPDATA%\KIBERone Games` каждой записи Windows, их можно удалить вручную.

**Удаление программы тьютора** снимает программу и правило брандмауэра. **Ключ школы, каталог и оценки остаются** в `%LOCALAPPDATA%\KIBERone Server`: если поставить программу снова, школа откроется тем же паролем. Чтобы удалить школу совсем, удалите эту папку, но сначала убедитесь, что есть резервная копия.

## 7. Где что лежит

| Где | Что |
| --- | --- |
| `C:\Program Files\KIBERone Сервер\` | Программа тьютора |
| `%LOCALAPPDATA%\KIBERone Server\` | Данные школы: зашифрованный ключ, каталог, файлы игр, список авторов, оценки |
| `C:\Program Files\Игры KIBERone\` | Программа учеников |
| `C:\ProgramData\KIBERone Games\school.json` | Метка школы. Меняет только администратор |
| `%LOCALAPPDATA%\KIBERone Games\` | Скачанные игры и последний каталог, у каждой записи Windows свои |
| `%APPDATA%\Игры KIBERone\` | Отметка «сегодня уже оценил» |

Что программа хранит и что нет, описано в [`bezopasnost.md`](bezopasnost.md).
