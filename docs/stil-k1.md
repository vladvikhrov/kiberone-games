# Стиль «K1 Игры»: детали на лабораторном стенде

Утверждён Владом 03.11.2026. Эталон — макет из четырёх экранов: https://claude.ai/artifact/K1DsPMWvpzSYDwFkWCRyXa. Этому стилю следуют все экраны приложения ученика и программы тьютора. Игры авторов могут выглядеть как угодно.

Образ: плоский строгий «инженерный» необрутализм. Серая столешница, на ней белые плашки с толстым чёрным контуром и жёсткой тенью, как детали, вырезанные из пластика. Подписи-маркировки моноширинным шрифтом.

## Цвета

| Токен | Значение | Где |
| --- | --- | --- |
| `--bg` | `#D6D9DC` | Фон экрана |
| `--plate` | `#FFFFFF` | Карточки, окна, кнопки |
| `--ink` | `#111111` | Основной текст, контуры, тени, выбранное состояние |
| `--ink-2` | `#4A4F55` | Второстепенный текст. Контраст 4.5:1 и на белом, и на сером |
| `--ink-desc` | `#2B2F33` | Описания |
| `--line` | `#C4C8CC` | Разделители внутри таблиц, 1px |
| `--fill` | `#E2E5E8` | Выбранная строка таблицы, полоса отсчёта |
| `--accent` | `#FF5B14` | **Только** кнопка «Играть», знак K1, полоса «ТЬЮТОР». Текст на нём чёрный |
| `--dim` | `rgba(17,17,17,0.55)` | Затемнение под окном, без размытия |
| Обложки-заглушки в макете | `#BFD8F0`, `#F2D6A2`, `#C9E4C5`, `#E3CBEA`, `#F5C6B8` | Пастельные фоны примеров |
| Полосы распределения оценок | `#111`, `#4A4F55`, `#7D838A`, `#A9AEB3`, `#D3D6D9` с контуром 1.5px | 5 → 1 звезда, отличаются светлотой |

Выбранное или активное состояние (фильтр, вкладка, оценка, статус «в каталоге») делается инверсией: фон `#111`, текст белый.

## Форма

- Контур 2px `#111`. Скругления 0, все углы прямые.
- Тени без размытия: карточки и большие кнопки `4px 4px 0 #111`, модальные окна `8px 8px 0 #111`, мелкие кнопки и знак K1 `3px 3px 0 #111`.
- Наведение: сдвиг на 2px вверх-влево, тень 6px. Нажатие: сдвиг 4px вниз-вправо, тень 0.
- Кликабельные элементы не меньше 44 × 44 px, звёзды оценки 64 × 64.
- Иконки только линиями в SVG, stroke 2–3px, `#111` или `currentColor`. Звёзды: заполненная `#111`, пустая — контур 1.5px, допустима половинка.

## Шрифты

Лежат внутри приложения (интернета нет), обе OFL с кириллицей.

- **Golos Text** 400–800: интерфейс. Заголовок экрана 28px 700, название в окне 26px 700, «Как тебе?» 34px 800, кнопка «Играть» 20px 800, текст 16px, межстрочный 1.5.
- **JetBrains Mono** 400/700/800: служебные подписи, метки, числа, знак K1 (800 18px), заголовки таблиц 12px, полоса «ТЬЮТОР» 800 13px с разрядкой 3px.

## Движение

- Окно игры вырастает из нажатой карточки: 200 мс, `cubic-bezier(0.2, 0, 0, 1)`, только `transform` и `opacity`. Закрытие 150 мс.
- При `prefers-reduced-motion: reduce` анимаций нет.
- Без пружин, отскоков, вылетов.

## Запрещено

Градиенты (кроме штриховки заглушки `repeating-linear-gradient(45deg, #E2E5E8 0 10px, #F0F2F3 10px 20px)`), размытие (`blur`, `backdrop-filter`), мягкие тени, скругления, эмодзи, фиолетовый неон, цветная полоса по левому краю карточки, 3D-иллюстрации, рекламные тексты вроде «Откройте мир возможностей».
