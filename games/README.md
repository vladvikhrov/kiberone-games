# Сборник игр KIBERone

Приложение и маркетплейс описаны в [корневом README](../README.md).

Короткие учебные игры для кибершколы KIBERone (Санкт-Петербург). Каждая игра рассчитана примерно на 30 минут и вставляется в обычный урок рядом с модулем методички. Игры работают офлайн: без интернета, без установки и без сервера.

Авторы: Влад и Кирилл, тьюторы KIBERone.

## Состав

| Папка | Игра | Для кого | Тема |
| --- | --- | --- | --- |
| `kiberpochta/` | Киберпочта | 4–5 класс | Мошеннические сообщения, пароли, личные данные |
| `vzlomai-seif/` | Взломай сейф (автор Кирилл) | 4–5 класс | Двоичная система: числа, буквы, пиксели |

`index.html` в этой папке — меню со списком игр.

## Запуск

**В приложении «Игры KIBERone».** Так игры получают дети на занятии: тьютор публикует `.kibgames` в программе «KIBERone Сервер», ноутбуки берут их по сети школы. Установка — [`docs/ustanovka.md`](../docs/ustanovka.md), как упаковать игру — [`docs/kak-sdelat-igru.md`](../docs/kak-sdelat-igru.md).

**Без приложения, на одном ноутбуке.** Скопируйте папку целиком и откройте `index.html` двойным щелчком в Chrome. Пульт `pult.py` для раздачи по сети удалён на этапе М5: его заменила программа тьютора.

Прогресс хранится во вкладке (`sessionStorage`): переживает F5 и пропадает, когда вкладку закрывают. На стартовом экране Киберпочты и в правой колонке Сейфа есть кнопка «Начать заново», если за ноутбук сел другой ученик. В Сейфе её нужно нажать дважды.

## Взломай сейф

Числа, буква, слово и картинка выбираются случайно для каждого ученика, поэтому у соседей задания обычно разные. «Сыграть ещё раз» выдаёт новые. Запас заданий лежит в `POOL` в начале скрипта `vzlomai-seif/index.html`.

## Киберпочта

Ученик работает оператором почты. Пять смен по порядку:

1. **Сортировка писем** (≈12 мин). Сначала знакомство с частями письма, потом 10 сообщений: «Доставить» или «Ловушка». В ловушке нужно найти улики кликом по подозрительным местам. Правила попадают в памятку справа.
2. **Что делать дальше** (≈5 мин). Ловушка уже сработала: из трёх вариантов выбрать правильный поступок. 6 случайных ситуаций из 9.
3. **Пароли** (≈5 мин). Из двух паролей выбрать тот, который дольше подбирать. Игра показывает примерное время подбора.
4. **Что можно выкладывать** (≈5 мин). 10 карточек в три коробки: «Можно всем», «Только знакомым в жизни», «Никому».
5. **Словарь** (≈5 мин). Соединить термин и объяснение.

Каждый ученик получает 5 случайных ловушек и 5 настоящих писем из запаса 14 + 14. Письма, ситуации, пары паролей и карточки идут в случайном порядке. Набор не меняется от F5, а новый оператор получает другой.

В конце выдаётся удостоверение оператора со звёздами и званием. Ученик показывает его тьютору, а тьютор начисляет кибероны по своим правилам. Звёзды дают за точность, а не за скорость.

Звёзды: письмо до 3 (верный ответ 2 + все улики не больше чем с одним промахом 1, настоящее письмо сразу 3), ситуация 2, пароль 2, карточка 1, словарь 6 минус ошибки. Всего 66.

### Как поменять тексты

Все письма, ситуации, пароли, карточки и термины лежат в `kiberpochta/data.js`. Чтобы добавить письмо, скопируйте любой объект из `mail` и поменяйте поля. Улика — это часть письма с полем `clue`. В ситуации из `help` верный ответ всегда пишется первым, на экране варианты перемешаются. Код в `game.js` менять не нужно.

| Файл | Назначение |
| --- | --- |
| `kiberpochta/index.html` | Разметка страницы |
| `kiberpochta/style.css` | Стили (шрифты Bahnschrift и Segoe UI есть в Windows 11) |
| `kiberpochta/data.js` | Все тексты игры |
| `kiberpochta/game.js` | Логика, звук (WebAudio, без файлов) |
